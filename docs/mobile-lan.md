# 手机局域网训练

## 连接

1. 电脑和 iPhone / Android 连接同一个可信 Wi-Fi。
2. 打开桌面版“设置”，在“手机访问”中点击“开启手机访问”。
3. 用 iPhone 相机扫描二维码。地址是家庭局域网固定地址，可保存书签并重复打开。
4. 手机上的洗牌、行动、结算和复盘独立运行；电脑不会看到手机手牌或历史。

默认端口是 `8765`。macOS 或 Windows 首次询问防火墙权限时，只允许“专用网络/本地网络”。固定地址不再使用一次性令牌，因此同一 Wi-Fi 的其他设备也能访问；只在可信家庭网络中开启，不要把端口映射到公网。

## 手机数据

- 历史、弱点和牌友设置保存在手机浏览器 IndexedDB，不写入电脑 SQLite。
- 在手机“历史牌局”中可导出或导入 v8 JSON；旧 v6/v7 文件会自动迁移，文件不含 API Key。
- Safari 清除网站数据会删除手机历史，建议定期导出。
- 当前版本使用局域网 IP。电脑 IP 改变时需重新扫码；旧地址下的数据不会自动迁移，可用 JSON 备份恢复。

## 断连

页面加载完成后，规则和牌局都在手机本地执行。电脑关闭服务或 Wi-Fi 短暂中断时，已打开页面仍可完成当前手并保存；关闭页面后，必须重新开启电脑服务才能再次进入。

## 故障排查

- 扫码打不开：确认同一 Wi-Fi、关闭访客网络隔离，并允许桌面应用访问本地网络。
- 二维码未显示：可先点击“复制固定地址”，发送到手机 Safari 打开。
- 提示端口占用：关闭占用 `8765` 的程序后重试。
- 历史无法保存：先导出当前牌局，检查 Safari 是否处于无痕模式或存储空间不足。

手机训练只使用虚拟筹码，不涉及真钱，不需要 Codex、Node、Python、API Key 或互联网。
