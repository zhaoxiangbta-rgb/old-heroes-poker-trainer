# 策略引擎 V3 交付审计

审计日期：2026-08-30
应用版本：1.5.0
策略版本：`strategy-v3`

## 结论

V3 是可离线运行、可回放、有版本与来源记录的本地实用策略。它已足以用于初、中级玩家训练，但不等于完整商业 Solver，也不声称已解出六人无限注和完整多人 GTO。

## 策略空间与来源

- 翻前：8 种行动节点 × 6 个位置 × 6 档筹码，共 288 节点。
- 每个节点包含 169 类起手牌，共 48,672 个手牌单元。
- 翻前来源：`expert-baseline-v3.0.0`，编译后每个单元频率归一化。
- 翻后：牌面家族 + 精确成牌构成 + 对手组合分段 + 尺寸弹性 + 未来街价值。
- 当前翻后独立 Solver 参考已验证 0 类；已通过属性审计、待外部 Solver 交叉验证的专家基线 3 类。

## 定向回归

### A2s，劫位，前面无人入池，100BB

- 节点：`audit:unopened:HJ:100:A2s`
- 来源：`strategy-pack-v3` / `explicit-matrix-v3`
- 混合策略：加注到 2.5BB 约 60%，弃牌约 40%。
- 回归意义：A2s 不再因为单一牌力阈值被无条件判为弃牌；位置、栈深和行动节点决定它的混合频率。

### A2s，A-A-7 翻牌，已成三条

- 节点构造：`board-pair-trips`，成牌类型是当下的三条，不是“未来成三条的概率”。
- 对手测试范围中，当前权益为 75%。
- 混合策略：过牌约 13.5%；1/3 池约 31.9%；1/2 池约 27.9%；2/3 池约 21.0%；满池及超池合计不足 6%。
- 回归意义：主要价值来自留住口袋对、7x 和部分听牌，而不是盲目把底池打大；保留过牌和小尺寸的后续街价值。

### 其他代表节点

- 干燥顶对：根据更差成牌和听牌的继续弹性混合多个尺寸，不再固定“成牌=满池”。
- 潮湿牌面坚果听牌：测试范围下以过牌与小尺寸半诈唬为主，尺寸越大权重逐级下降。
- 多人池：独立组合范围、身后玩家、赃补牌和可赢底池同时进入本地有限预算解析；置信度低于单挑蓝图。

## 自动门禁

| 命令 | 验证内容 |
| --- | --- |
| `npm test` | 规则、策略、训练、持久化和界面回归 |
| `npm run test:strategy` | 固定回归 + 10 批随机压力测试，检查筹码守恒、动作合法与显式降级 |
| `npm run audit:strategy-v3` | 288 节点、48,672 单元完整性，以及 3 类翻后属性节点 |
| `npm run test:performance` | 桌面决策 P95 ≤ 150ms，移动压缩包加载后查找 P95 ≤ 250ms |
| `npm run build` | 编译两端策略包、TypeScript、桌面 Web 资源和移动 PWA |
| `npm run verify:mobile-bundle` | 移动预缓存、包哈希、隐私名称与密钥泄漏门禁 |
| `npm run verify:desktop-data` | 桌面 SQLite / Keychain / V3 版本合同与图标资源门禁 |

2026-08-30 本机门禁结果：桌面 V3 决策 median 70.46ms、P95 88.09ms；移动策略包加载后的 100 次批量查找 median 0.46ms、P95 0.76ms。性能数字只是当前机器的回归证据，门禁上限仍以 150ms / 250ms 为准。

## 已知边界

1. 三类翻后基线尚未与外部商业 Solver 数据库交叉验证，因此只标记为专家基线。
2. 多人池采用固定时间/样本预算的近似解析，不等于完整多人均衡。
3. 玩家画像仅能在有上限的范围内偏离基线，不改变洗牌、发牌、合法动作或结算事实。
