# 局域网手机版验收记录

版本：1.1.6
目标机型：iPhone 14 Pro Max（430 × 932 CSS px）  
验收日期：2026-08-26

## 已自动验证

- TypeScript / React：41 个测试文件、243 项测试通过；ESLint 和生产构建通过。
- Rust / Tauri：15 项测试通过；macOS 1.1.6 DMG 生成。
- Windows x64：交叉编译生成 PE32+ GUI 可执行文件和免安装 ZIP；本次没有 Windows 真机，因此不声称已完成 Windows 运行验收。
- Playwright：2 项 iPhone 14 Pro Max 竖屏/横屏交互验收通过。
- Playwright WebKit：安装版局域网页面启动验收通过，无脚本错误或资源加载失败。
- 手机主程序使用 Safari 14 兼容的单文件 IIFE 构建，不再依赖 ES Module 加载链。
- 手机首页内嵌主程序与样式，不再依赖 Safari 发起第二次主脚本请求。
- 局域网服务对大资源协商 gzip，手机首页传输体小于 150KB。
- 局域网服务改用 tiny_http 处理连接、请求解析和完整响应，替代手写 TCP HTTP 实现。
- 手机竖屏和横屏均无水平溢出，牌桌与操作区不重叠。
- 从发牌、行动、结算到复盘使用与桌面版相同的本地规则引擎。
- 历史、弱点与设置保存到手机 IndexedDB；JSON v8 可导入导出，旧 v6/v7 文件可迁移。
- 二维码和文字链接指向可重复使用的家庭局域网地址，不含一次性令牌。安全边界是可信 Wi-Fi，不得映射到公网。
- 服务只提供内嵌手机页、静态资源和健康检查，拒绝目录穿越与桌面入口。
- 离线包中不含 API Key，不含私有牌友名称。

## 人工验收边界

本次在 macOS 上用 Chromium 的 iPhone 14 Pro Max 窗口完成布局与交互自动验证，没有冒充真机 Safari 验收。早间验收时需用真实 iPhone 检查：首次“本地网络”授权、相机扫码、Safari 后台恢复、Wi-Fi 切换与防火墙提示。

当前采用局域网 IP 地址，未实现 mDNS 固定域名；电脑 IP 变化后需重新扫码。
