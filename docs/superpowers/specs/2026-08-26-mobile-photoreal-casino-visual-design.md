# 移动牌桌写实赌场视觉升级设计

## 目标

在不改动本地规则引擎、行动流程和离线能力的前提下，将移动牌桌从“程序化控件界面”升级为接近用户参考图的写实高端俱乐部视觉。首要验收标准是好看、醒目、不遮挡，而不是装饰数量。

## 已确认的设计方向

- 整体选择 A“样图写实版”。
- 桌面使用深翡翠台呢，桌边使用黑色皮革和克制的拉丝黄金包边。
- 人物头像由 Image 2 生成，为六名不可识别的虚构人物，不使用名人、真实用户或以前的私人名称。
- 牌体可比现版略小，但点数和花色必须显著放大。
- 头像、姓名/位置/余码铭牌、下注筹码标签保持三层独立，互不覆盖。
- 操作坞继续独占底部安全区，不压住公共牌、底池、对手余码或下注信息。

## 视觉令牌

### 色彩

- 翡翠台呢 `#073A2B`：桌面主色。
- 深绿阴影 `#031B14`：桌面边缘和暗部。
- 黑色皮革 `#11100D`：桌边、推杆、操作坞。
- 拉丝黄金 `#C79A49`：结构边线、焦点和 ALL IN。
- 象牙纸牌 `#F2EEE4`：牌面和主操作筹码。
- 红花色 `#B72E28`：红桃、方片和弃牌警示。

### 字体

- 品牌与 ALL IN：使用古典高对比衬线字体，仅用于标题和金色特效。
- 中文操作和人物信息：使用系统黑体中高字重，保证小屏可读性。
- 筹码、余码和底池数字：使用等宽数字特性，避免金额变化时跳动。

## Image 2 资产

### 人物头像

生成六张独立方形头像，程序内使用圆形裁切：

1. 冷静策略型：深色夹克，目光专注。
2. 轻松老练型：稍年长，神情温和但有阅历。
3. 大胆攻击型：红棕色外套，神情自信。
4. 理性技术型：简洁衬衫，冷色轮廓光。
5. 新手稳健型：年轻、自然，不做夸张表情。
6. 主角型：中性、干净、亲和，作为玩家默认头像。

统一约束：肩部以上近景，正面或轻微侧脸，暗色俱乐部背景，暖金轮廓光，脸部清晰，不出现筹码、文字、水印、品牌标识或多人。人物必须完全虚构。

### 材质资产

- 可循环的翡翠台呢纹理。
- 可循环的黑色皮革纹理。
- 实体筹码按钮的九宫格切片：红棕弃牌、象牙跟注、黄金加注/全下。

材质图不承载任何文字，所有文字由程序渲染，避免生成图文字失真和多语言不可控。

## 纸牌设计

- 手牌参考尺寸：宽 52–56 px，高 72–78 px。
- 公共牌参考尺寸：宽 46–50 px，高 64–70 px。
- 点数占牌宽约 44%，使用粗衬线字体。
- 花色占牌宽约 52%，位于点数下方，不使用细小角标。
- 红桃和方片使用高饱和暗红；黑桃和梅花使用近黑色。
- 纸牌保留轻微纸纤维、暖白色差、薄阴影和细边线，不使用强烈拟物反光。

## 按钮与推杆

- 弃牌和主操作按钮形成两枚独立实体筹码，不使用通用圆角矩形。
- 按钮文字使用 HTML 渲染，保持清晰、可缩放和无障碍。
- 按下时使用 80–120 ms 的下沉、内阴影和筹码轻响。
- 推杆使用黑皮革凹槽和黄铜滑块，最顶端显示 `ALL IN`，中部显示当前金额。
- 半池、2/3 池、底池使用细金边胶囊按钮，不与主操作筹码抢层级。

## 布局和状态

- 牌桌与操作坞保持不重叠的独立坐标系。
- 头像、铭牌、底牌、下注标签使用座位专用布局，左席向右展开，右席向左展开，不允许越出屏幕。
- 弃牌后头像和铭牌降低饱和度，但余码仍可读。
- 轮到谁行动时，只高亮其头像外圈和铭牌边线，不放大整个座位。
- 下注动画使用 2–3 枚筹码从玩家座位抛物线飞入底池，时长 220–320 ms。
- ALL IN 使用不超过 450 ms 的金色闪光和短促文字特效，不持续闪烁。

## 资产与离线交付

- 所有生成资产纳入 `public/assets/mobile-casino/`，不从外网加载。
- 头像输出 WebP，单张目标 80–150 KB；纹理和按钮资产优先 WebP/PNG，并保留高 DPI 清晰度。
- 打包、PWA 预缓存、断网启动和第二次启动必须全部成功。
- 密钥、人名本地配置和私有信息不进入任何图像元数据、构建产物或 Git 历史。

## 验收标准

1. iPhone 14 Pro Max 竖屏、紧凑竖屏和横屏下，头像、铭牌、底牌、下注、公共牌、底池和操作坞无交叠、无裁切。
2. 圆形头像有效直径不小于 48 px；人脸在实际裁切中仍清晰可辨。
3. 手牌点数不小于 24 px，公共牌点数不小于 21 px；花色的视觉宽度不小于牌宽的 45%。
4. 操作按钮在触摸设备上的有效点击区不小于 44×44 px，有按下反馈，快速重复点击不会跨越多个行动。
5. 与参考图对比时，重点元素必须呈现真实材质层次，不得使用字符、Emoji、通用渐变圆或简单内联 SVG 作为最终头像和主按钮资产。
6. 原有规则引擎、种子重放、IndexedDB、离线降级和桌面操作测试保持通过。

## 测试方案

- 组件测试：头像资产映射、牌面点数/花色 DOM 结构、按钮禁用与反馈。
- 视觉几何测试：三种视口的元素尺寸、交叠、越界和触摸区。
- 截图对比：与用户参考图在相同屏幕比例下做设计 QA，消除所有 P0/P1/P2 差异后交付。
- 回归测试：完整单元测试、构建、移动 PWA 预缓存验证和断网测试。
