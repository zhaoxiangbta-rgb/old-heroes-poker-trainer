# 移动端与 PC 端统一三区操作台设计

## 设计基准

以已确认的样图 `exec-f57f8a40-99c4-4ab5-9425-c4a76030407f.png` 为视觉基准。移动端按样图落地；PC 端使用同样的信息顺序、材质和交互规则，在牌桌主区底部做宽屏适配，不侵占右侧分析栏。

## 统一信息架构

- 上层是水平金额轨道，当前金额显示在轨道上方。
- 轨道档位为 `最低 / 半池 / 2/3池 / 底池 / ALL IN`，以轨道中心为基准均匀排列，不根据实际筹码值挤在轨道一端。
- 轨道仍支持所有合法整数金额；档位是吸附点，不是唯一可选值。
- 下层是三区：左侧尺寸区、中间手牌区、右侧动作区。
- 左侧尺寸区显示 `半池 / 2/3池 / 底池` 三枚等大筹码按钮，左下角显示 `余码 N · 位置`。
- 中间只显示两张大手牌，不在手牌下增加文字行，以降低整体高度。
- 右侧动作区固定三枚等大筹码位：`弃牌 / 过牌 / 跟注或下注加注`。当前不合法的动作保留位置但变暗并禁用，不引发布局跳动。

## 移动端

- 针对 iPhone 14 Pro Max 的 430 px CSS 宽度优先设计，同时覆盖 430×760 紧凑竖屏和 932×430 横屏。
- 底部操作台高度目标 132–142 px，必须低于现有 146 px 并且不覆盖牌桌。
- 左右各三枚筹码平均分配可用宽度，触摸目标不小于 48×48 px；中间手牌单张不小于 56 px。
- 三区各有简洁黑皮革/黄铜边界，区内元素等距，区与区之间保留 6–8 px 缝隙。

## PC 端

- 操作台仅占据牌桌主区宽度，不跨越可调节的右侧分析栏。
- 上层轨道居中，允许鼠标拖动、方向键调整和数字输入；数字输入作为轨道金额显示的可编辑状态，不单独占一列。
- 左侧三枚尺寸按钮、中间手牌、右侧三枚动作按钮使用与移动端相同的顺序，但允许更宽的标签和 56–64 px 按钮。
- PC 端保留 Enter 确认金额、Space 过牌、Escape 二次确认弃牌的键盘逻辑。

## 交互规则

- 所有金额、最小加注、最大加注、过牌、弃牌、跟注、下注和加注可用性仍只来自本地规则引擎。
- 移动端与 PC 端共用金额选项、档位目标和动作转换纯函数，不建立两套规则。
- 点击左侧尺寸只更改金额，不直接提交；点击右侧主动作才提交。
- ALL IN 是轨道档位和主动作状态，保留金色艺术字、筹码飞行动画和声音。
- 保留现有防连点锁和错误恢复逻辑。

## 验收

- 组件测试覆盖三个尺寸位、三个固定动作位、禁用状态、尺寸不直接提交、金额变化和防连点。
- 移动视觉测试覆盖 430×932、430×760、932×430，验证高度、三区对齐、触摸尺寸、无遮挡和横杆档位均匀。
- 新增 PC 视觉测试，在 1440×900 和 1100×760 验证操作台不侵占分析栏、三区无重叠、手牌与按钮清晰。
- 完整运行单元测试、代码检查、桌面与移动构建、PWA 离线测试和视觉测试。

## 不在本次范围

- 不修改牌桌座位、对手头像、右侧分析内容或规则引擎。
- 不增加新下注尺寸或外部网络依赖。
