# 桌面端样图等比舞台设计

## 目标

桌面端以用户确认的竖向扑克样图为视觉基准，不再让牌桌、下注区和左右栏目随窗口宽度各自拉伸。1440×900 为标准验收尺寸，1100×760 为紧凑验收尺寸；紧凑尺寸采用整体缩放和有限压缩，不重新打散构图。

## 总体结构

桌面工作区继续保留可调宽度的右侧教学栏。左侧游戏区内部建立独立的等比舞台，包含牌桌和底部下注区，两者共享同一条中心轴。教学栏宽度变化只改变舞台的可用缩放比例，不改变舞台内部相对位置。

标准舞台自上而下分为：牌局信息条、椭圆牌桌、底部下注控制。牌桌保持厚黑皮革外圈、金色压边和深绿色绒面；玩家围绕椭圆桌缘固定分布。桌面不能被横向拉成过扁的椭圆，也不能让座位越出舞台。

## 牌面标准

牌面使用暖象牙白纸张质感、低反光阴影和细灰边，不使用纯白网页卡片。牌的物理尺寸保持克制，但点数字与花色占据更大面积：数字靠左上，花色紧邻其下；红桃、方片使用深红，黑桃、梅花使用近黑。公共牌与玩家手牌使用同一视觉组件，仅通过尺寸变量区分。

牌背使用深绿、黑色和金色细线构成的专属图案。桌面玩家底牌必须与姓名牌、头像和下注筹码分开，不允许互相覆盖。

## 中心底池筹码堆

公共牌与底池数字之间增加真实筹码堆，使用红、蓝、绿、黑、金五类本地筹码素材。筹码数量按底池区间映射为视觉层级，不逐枚等同真实金额：小底池为两到三叠，大底池增加叠高和颜色，但始终限制在公共牌下方的安全区。

底池金额只显示一次，固定放在筹码堆正上方，格式为“底池 64”。筹码堆内部、公共牌附近和状态条不得重复显示底池金额。下注动画仍从玩家下注区飞向中心，结束后中心筹码堆短暂回弹；结算时筹码堆向赢家方向移动。减少动态效果设置下停用位移动画。

## 玩家座位标准

每个玩家座位严格参照样图，由彼此独立的四层信息组成：

1. 最上方为醒目的圆形头像，金属外圈和当前行动光环只作用于头像，不扩大整块座位。
2. 中文位置标签贴近头像外侧，位置由座次决定，不能压在头像或姓名上。
3. 姓名与余码位于头像正下方的黑金铭牌中，第一行姓名、第二行“余码 168”；全下时第二行显示金色 `ALL IN`。
4. 本街下注使用独立筹码图标和金额，放在头像朝向桌心的一侧，不能出现在姓名铭牌内部。

玩家底牌位于姓名铭牌下方并与下注筹码错开。弃牌状态在头像或牌背上添加清晰蒙层，但仍保留姓名、位置和余码可读性。所有玩家使用同一结构与尺寸，仅按桌边方向调整位置标签、底牌和下注筹码朝向。

## 底部下注区

下注区固定两层，始终与舞台同宽：

1. 上层为横向下注杆，保留精确金额输入与最低、半池、2/3池、底池、ALL IN 五个吸附点。吸附点以等距锚点排列，当前金额显示在滑块上方。
2. 下层为严格三栏。左栏是半池、2/3池、底池；中栏是玩家两张手牌；右栏是弃牌、过牌、跟注或加注。中栏基于整个舞台的几何中心定位，不通过左右栏剩余空间推算，因此左右按钮文案变化时手牌仍保持居中。

三栏高度一致。左右控制使用实体筹码按钮，但字号、触控面积和间距统一；中间手牌尺寸显著高于座位底牌。横杆和下层之间保留明确间距，不压住牌面。

## 响应式规则

- 1440×900：按标准尺寸完整呈现。
- 1100×760：舞台整体缩小；头像、牌面、筹码和按钮按同一比例缩放，正文保留最低可读字号。
- 低于桌面最小宽度时使用应用现有最小窗口限制，不引入横向滚动。
- 右侧教学栏可调；舞台在剩余区域居中，并使用统一缩放因子。

## 组件边界

- `DesktopPokerStage`：计算舞台尺寸和缩放比例。
- `PokerTable`：负责牌桌状态、公共牌、中心底池与座位编排。
- `PotChipStack`：只负责由底池金额生成确定性的筹码视觉和动画状态。
- `PlayerSeat`：继续保持头像、姓名牌、底牌和下注筹码四区分离。
- `ActionControls`：保持游戏动作与合法性不变，只重排横杆和三栏。
- `PlayingCard`：统一牌面语义与尺寸变量。

规则引擎、下注合法性、随机种子、复盘和持久化逻辑不修改。

## 验收标准

- 1440×900 与 1100×760 截图中，牌桌宽高比误差不超过 2%。
- 底部手牌中心与左侧游戏舞台中心偏差不超过 2 像素。
- 横向下注杆完整可见，五个吸附点顺序和间距稳定。
- 中心筹码堆不与公共牌、底池数字、玩家座位重叠。
- 页面中“底池”金额只出现一次，并固定在中心筹码堆上方。
- 玩家头像、中文位置标签、姓名余码铭牌、底牌、下注筹码五个区域互不重叠。
- 六个座位使用同一视觉结构；下注筹码均处于玩家朝向桌心的一侧。
- 公共牌与手牌的数字和花色在两种验收窗口中均清晰可读。
- 所有现有规则、交互、PWA 与离线构建测试继续通过。

## 非目标

本轮不修改移动端牌桌结构，不调整 GTO 策略或牌局规则，不新增网络服务，也不发布 GitHub。
