# 独立离线移动版 PWA 设计

## 目标

- 将现有局域网移动版升级为可安装的独立 PWA。
- 用户使用 iPhone Safari 首次访问固定 HTTPS 地址并添加到主屏幕后，即使电脑关闭或手机断网，也能启动应用、完成牌局并保存记录。
- 同一套静态应用兼容 iPhone 14 Pro Max 和主流安卓浏览器，不依赖 Codex、Node、Python、桌面程序、API Key 或后端服务。
- 继续复用桌面版的本地规则引擎和训练策略，避免产生规则不同的简化移动版。

## 交付路线

第一版采用静态 HTTPS PWA，并发布到项目对应的 GitHub Pages 固定地址：`https://zhaoxiangbta-rgb.github.io/old-heroes-poker-trainer/`。GitHub Pages 只分发静态文件，不接收或保存牌局数据。用户首次安装和获取版本更新时需要联网；完成一次成功加载后，日常训练可以完全离线。

暂不采用以下方案：

- Capacitor 原生套壳：需要 iOS 签名、分发和更复杂的更新流程，不适合作为当前最简交付。
- 局域网自签名 HTTPS：需要在手机信任证书，使用成本和故障概率都较高。

## 应用结构

### 移动应用

- 继续以 `src/mobile` 为移动端入口。
- 复用 `src/game`、`src/engine`、`src/policy` 和 `src/training`，本地规则引擎仍是唯一事实源。
- 复用 IndexedDB 仓库保存随机种子、完整牌局、决策、评分、标签和设置。
- 保持匿名公开构建约束，不把本地玩家姓名、密钥或私人配置放入 PWA、日志或导出文件。

### PWA 外壳

- 增加 Web App Manifest，声明中文名称、短名称、独立显示模式、主题颜色、背景颜色、纵向优先和应用图标。
- 增加 iOS 所需的主屏幕图标、状态栏和安全区适配。
- 使用已有品牌图标生成 PWA 所需尺寸，不为移动端引入另一套品牌标识。
- 在应用内显示当前版本、安装状态、联网状态和离线可用状态。

### 离线缓存

- Service Worker 预缓存移动应用的 HTML、JavaScript、CSS、Manifest、图标及必要静态资源。
- 应用外壳采用 cache-first；导航请求在网络失败时回退到已缓存首页。
- 不缓存局域网健康检查、密钥、用户导出或运行时调试信息。
- 首次缓存完整成功后才显示“已可离线使用”，避免给出错误承诺。

## 版本更新

- 每次构建使用应用版本和内容哈希生成独立缓存名。
- 新 Service Worker 下载完成后提示“新版本已准备好”，由用户确认后刷新切换，避免牌局中途被强制重载。
- 激活新版本时只清理本应用的旧静态缓存，不删除 IndexedDB 牌局数据。
- 如果更新下载失败，继续运行现有缓存版本，并显示中文提示，不进入黑屏或无限启动状态。
- 设置页显示应用版本和缓存版本，便于截图排错。

## 数据与隐私

- 所有牌局和设置默认仅保存在当前手机浏览器的 IndexedDB。
- 提供不含密钥的 JSON 导出、导入和清空入口；导入先校验文档版本和数据结构。
- 清除 Safari 网站数据、卸载主屏幕应用或系统回收存储可能删除记录，因此设置页明确提示并鼓励定期导出。
- 第一版不做账号、云同步或手机与桌面自动同步。

## 手机体验

- 以 iPhone 14 Pro Max 的竖屏安全区为主要验收尺寸，同时兼容较窄安卓屏幕。
- 主屏幕启动时采用独立应用模式，不显示浏览器地址栏。
- 顶部和底部操作区避开刘海、灵动岛和 Home 指示条。
- 旋转屏幕不丢失当前牌局；竖屏为主，横屏保持可操作但不做单独桌面布局。
- 启动页应区分“首次下载”“正在读取本地数据”“已离线启动”和可恢复错误。

## 发布

- 增加独立 PWA 构建产物和 GitHub Pages 发布工作流。
- 发布目录只能包含匿名静态资源，并在上传前运行隐私扫描和资源完整性验证。
- README 增加中文安装说明：iPhone 使用 Safari 打开固定地址，选择“分享”→“添加到主屏幕”；安卓使用浏览器的“安装应用”。
- 桌面局域网入口继续保留用于开发和临时测试，但不再是独立移动版的运行依赖。

## 错误处理

- Service Worker 不受支持时，应用仍可联网运行，并明确提示无法保证离线启动。
- IndexedDB 不可用或容量不足时，牌局继续在内存中运行，同时提示立即导出，不伪装为已保存。
- 静态资源损坏时显示可操作的恢复页，提供重试和清理应用缓存按钮，不出现 `module-timeout` 或永久加载状态。
- PWA 只处理本应用路径，避免 Service Worker 干扰项目其他 GitHub Pages 页面。

## 验收与测试

- 单元测试验证 Manifest、缓存资源清单、版本化缓存、旧缓存清理和导航离线回退。
- 组件测试验证中文安装提示、离线就绪状态、更新提示、版本信息、存储异常和恢复入口。
- IndexedDB 测试验证断网重启后牌局、账本、训练进度和设置仍可恢复。
- Playwright WebKit 生产测试覆盖首次联网访问、Service Worker 激活、断网刷新、离线重新启动和更新流程。
- 移动视觉测试覆盖 iPhone 14 Pro Max 竖屏安全区、操作区、牌桌和设置页。
- 构建验证确保输出不请求局域网地址、不包含私人姓名或密钥，并且所有预缓存资源真实存在。
- 完成现有前端、规则引擎、持久化、Rust 和匿名构建测试，保证桌面版不回退。

## 本版完成标准

满足以下条件才视为交付完成：

1. 固定 HTTPS 地址可以在 iPhone Safari 打开并添加到主屏幕。
2. 成功打开一次后，关闭电脑并断开手机网络仍能从主屏幕启动和完成一手牌。
3. 退出并重新打开 PWA 后，牌局记录和训练数据仍存在。
4. 新版本不会在牌局中途强制刷新，失败更新不会破坏旧版本或 IndexedDB。
5. 页面明确显示应用版本、缓存版本、联网状态和离线可用状态。
6. 自动测试、生产构建、隐私扫描和移动端 WebKit 验证全部通过。
