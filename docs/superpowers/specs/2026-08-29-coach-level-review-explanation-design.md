# 教练级复盘解释设计

**日期：** 2026-08-29  
**状态：** 已确认，待实施计划  
**适用项目：** `poker-decision-trainer`

## 1. 目标

把当前以“有效组合、权益、SPR、样本、覆盖率”为中心的计算报告，改成初中级牌手能够直接用于下一手牌的教练式复盘。

复盘仍保留全部专业事实，但默认先回答：

1. 我的牌在当前局面属于什么强度层级？
2. 对手可能有哪些类型的牌，各占多大比例？
3. 对手为什么会采取当前行动？
4. 我的牌会怎样改善，又有哪些伪改善和反超风险？
5. 弃牌、跟注、过牌或加注分别靠什么赚钱？
6. 哪些条件变化会改变推荐动作？

本功能只解释本地规则、范围和 EV 引擎已经计算出的事实。不得根据本手输赢倒推评价，也不得让可选语言模型覆盖本地结论。

## 2. 信息层级

每个英雄决策点使用三层结构。

### 2.1 默认层：教练结论

默认展示一段可直接执行的中文分析，包含：

- 当前牌型及相对强度，不使用“有一定摊牌价值”这类空泛表述。
- 面对对手完整范围的权益，以及面对其继续范围的权益。
- 对手范围中的强成牌、普通一对、强听牌、弱听牌和空气比例。
- 当前下注价格、身后玩家风险及它们对动作的影响。
- 推荐动作、主要收益来源和不推荐动作的主要问题。

示例：

> 你目前是顶对中等踢脚，在自己走到这里的合理范围中约处于前 32%。对手的估计范围约有 18% 两对以上、37% 普通一对、28% 听牌和 17% 弱牌或诈唬。面对其全部下注范围，你约有 36.7% 权益；面对愿意继续对抗加注的更强范围，权益会下降。当前跟注价格只要求约 18.8% 胜率，但身后还有两名玩家，因此推荐跟注控池，不建议主动扩大底池。

### 2.2 解释层：六张教学卡片

1. **你的牌力**：当前牌型、自身范围百分位、全部范围权益、继续范围权益。
2. **对手可能持牌**：按互斥类型展示概率，合计必须为 100%。
3. **对手行动含义**：各类持牌采取本次动作的估计频率，以及本次行动如何改变范围。
4. **后续牌路**：已成牌、仍保持当前牌型、升级牌型、干净改善、脏改善和被反超风险。
5. **动作比较**：每个合法动作的 EV、收益来源、风险和适用条件。
6. **结论变化条件**：下注尺度、人数、身后行动、对手倾向或牌面变化达到何种程度时改选其他动作。

### 2.3 专业层：可展开计算依据

折叠展示：

- 有效组合数及其变化。
- 精确权益、所需胜率、SPR、补牌数。
- 枚举或采样方式、样本量、覆盖率、置信度和计算器版本。

专业层中的每个术语附一行中文解释。专业数据不能单独承担教学结论。

## 3. 牌力与范围表达

### 3.1 英雄牌力

每个决策点输出：

- `madeHandLabel`：高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺。
- `heroRangePercentile`：英雄手牌在自己合理到达范围中的相对百分位。
- `equityVsFullRange`：面对对手当前完整范围的权益。
- `equityVsContinueRange`：采取下注或加注后，面对对手继续范围的权益。

百分位和权益必须明确区分。百分位表示“在自己的范围里有多强”，权益表示“对对手范围能赢多少”。

### 3.2 对手范围类型

翻后范围按互斥类别汇总，所有类别概率合计为 100%：

- 两对及以上。
- 顶对或超对。
- 中对、底对及口袋对子。
- 强听牌：高权益同花听牌、开放式顺子听牌、组合听牌。
- 弱听牌：卡顺、弱同花听牌及低权益改善牌。
- 弱牌或空气。

翻前使用适合翻前的互斥类别：高口袋对子、中小口袋对子、强 Ax、同花连张、宽跟注牌和弱牌。

UI 显示“本地范围模型估计”和置信度，禁止把范围概率写成确定事实。

### 3.3 行动反应

对推荐的英雄动作，估计对手：

- 弃牌、跟注、加注概率。
- 继续范围的牌型构成。
- 各类牌采取该反应的主要频率。

多人池分别计算各对手，再给出“至少一名身后玩家继续或加注”的联合风险；不能简单相加导致概率超过 100%。

## 4. 成牌路径语义

牌型路径必须避免把“最终仍为三条”误写成“成为三条的概率”。

- 先显示当前已成牌，例如“当前已成三条”。
- 显示“到河牌至少保持三条 100%”。
- 互斥终局分布使用“仍为三条”“升级为葫芦”“升级为四条”等文案，合计为 100%。
- “下张”改成“下一张发出后”，并明确是最终类别还是改善事件。
- 补牌区分干净改善、脏改善、伪改善和对手反超牌。

## 5. 中文解释生成

解释由确定性本地模板生成，不依赖外接 AI。模板输入只接受结构化事实，输出顺序固定为：

1. 当前牌力。
2. 对手范围。
3. 价格与人数。
4. 动作比较。
5. 推荐与变化条件。

模板必须处理边界情况：

- 权益高于所需胜率但身后风险过大。
- 加注对完整范围有优势，但对继续范围明显落后。
- 当前已经成牌，不能再描述为“击中该牌型”。
- 河牌没有未来补牌时，不展示补牌段落。
- 翻前不展示翻后牌型路径。
- 计算置信度不足时使用“倾向于”，并明确缺失原因。

可选 OpenAI-compatible 模型只能在结构化事实范围内润色或回答追问；本地模板始终可完整离线使用。

## 6. 数据结构

在现有深度复盘结果上新增版本化解释事实：

```ts
type CoachDecisionFacts = {
  madeHandLabel: string;
  heroRangePercentile: number | null;
  equityVsFullRange: number;
  equityVsContinueRange: number | null;
  opponentBuckets: Array<{
    kind:
      | "strong-made" | "top-pair" | "medium-made" | "strong-draw" | "weak-draw" | "air"
      | "premium-pair" | "medium-pair" | "strong-ace" | "suited-connector" | "wide-call" | "weak-preflop";
    probability: number;
  }>;
  opponentResponses: Array<{
    action: "fold" | "call" | "raise";
    probability: number;
  }>;
  atLeastOnePlayerBehindContinues: number | null;
  runoutSummary: Array<{
    label: string;
    probability: number;
    mutuallyExclusive: boolean;
  }>;
  recommendationReasons: string[];
  changeConditions: string[];
  confidence: number;
};
```

范围类别、行动反应和终局互斥牌型分别校验概率和为 1。旧版复盘没有这些字段时继续显示原数据，但标记“旧版复盘”，并允许使用当前版本重新精算。

## 7. 界面调整

- “范围变化”默认改为“对手可能有什么牌”。
- “赔率与补牌”默认改为“你的牌力与后续变化”。
- 决策卡顶部增加教练结论，不超过一个正常屏幕段落。
- 六张教学卡片默认展开，专业计算依据默认折叠。
- 概率使用短条形图和文字同时表达，不只依赖颜色。
- 桌面和移动端使用相同事实与文字，移动端改为纵向卡片，不缩小字号硬塞。

## 8. 验证要求

### 8.1 数学与语义

- 对手互斥范围类别合计为 100%，允许显示舍入误差但内部误差小于 `1e-9`。
- 行动反应概率合计为 100%。
- 已成三条示例必须显示“至少三条 100%”，而不是把“仍为三条”冒充成牌概率。
- 面对全部范围和面对继续范围分别计算、分别命名。
- 多人身后风险使用联合概率，并通过手工构造场景核对。

### 8.2 教学质量

- 每个建议至少包含牌力、范围、价格或人数中的三个具体依据。
- 禁止单独输出“有一定摊牌价值”“范围较宽”“需要谨慎”等无量化支撑的句子。
- 推荐跟注时解释所需胜率与预计权益；推荐下注或加注时解释更差跟注范围或弃牌收益。
- 明确指出改变结论的至少一个条件；不存在合理变化条件时说明原因。

### 8.3 回归与性能

- 复盘解释不读取未摊牌对手的真实底牌。
- 相同种子、状态、策略版本和计算配置得到相同文本与概率。
- 解释生成不重复运行昂贵权益计算，只消费精算结果。
- 桌面、移动端、历史牌局和 JSON 导入后的复盘一致。
- 旧数据可打开，牌局实时操作性能不受影响。

## 9. 实施边界

本阶段只增强复盘事实、解释和展示，不重做牌桌、下注区、对手实时决策策略或深度计算预算。若现有深度结果缺少继续范围权益和范围类别概率，只新增必要的统计输出，不另建第二套范围引擎。
