# Image 2 统一牌桌视觉系统设计

## 目标

以已确认的两张 Image 2 设计稿为视觉基准，重新生成项目所需的头像与筹码图片，并同步更新移动端和 PC 端牌桌。两端必须使用同一套资产、色彩、材质和状态语言，不再出现移动端写实、PC 端仍为旧文字座位或 CSS 筹码的分裂。

设计基准：

- 移动端：`exec-0a1f5cb4-9aa5-42a6-812d-81e74c4d5189.png`
- PC 端：`exec-451207f5-237f-4696-b65c-47a6202cb193.png`

## 视觉方向

- 深绿羊毛桌布、黑色马鞍皮革、拉丝古金、暖象牙牌面与克制的暗红色。
- 现代写实扑克软件，不做奇幻游戏、霓虹电竞或过度金色花纹。
- 重点信息按牌桌真实物理关系呈现：头像与身份牌在外圈，下注筹码朝向底池，公共牌和底池始终无遮挡。
- PC 与手机只做响应式重排，不改变资产风格或交互含义。

## 新资产

### 六个玩家头像

生成六张独立、无真实人物指向的正方形头像：

1. 资深战术家：成熟、威严、善于读牌。
2. 冷静分析者：克制、理性、专注。
3. 幸运型魅力玩家：自信、松弛、带一点玩心。
4. 高赌性进攻玩家：大胆、强势、行动感明显。
5. 稳健新手：谨慎、安静、容易识别。
6. 普通入门玩家：友善、朴素、与第五位明显不同。

六个头像必须以已确认样图中的人物形象为直接参考，不生成另一套近似人物。所有头像采用相同光线、背景和金色圆框适配规则，但人物轮廓、姿态、服饰和主色必须显著不同。稳定玩家 ID 映射到固定图片，改名、重放或重启不换脸。

### 牌面系统

- 手牌与公共牌必须匹配样图的清晰牌面：暖象牙纸张、轻微纸纤维、克制的旧化边缘、深色窄阴影和小圆角。
- 点数使用高对比粗衬线字，花色独立放大；红桃和方片使用深赌场红，黑桃和梅花使用近黑色。
- 动态点数和花色继续由程序渲染，保证完整 52 张牌、发牌动画和无障碍标签；不得把固定牌值烘焙成图片。
- 移动端操作区手牌、牌桌手牌和公共牌使用同一个 `PlayingCard` 组件和同一套视觉令牌，仅按场景调整卡片尺寸。
- 牌背同步改为黑绿底、古金细纹的品牌牌背，保持与样图桌面材质一致。

### 筹码资产

- 下注筹码：至少红、蓝、绿、黑、金五种面额色，统一陶瓷赌场筹码质感；用于玩家本街投入、底池和筹码飞行动画。
- 操作筹码：弃牌暗红、过牌墨绿、主操作金色、ALL IN 黑金高亮。
- 图片不得带固定金额或玩家名称；按钮文字继续由 HTML 覆盖，以便显示动态跟注或加注金额。
- 所有资产存入项目 `public/assets`，进入 PWA 离线预缓存，不依赖网络。

## 玩家座位结构

移动端和 PC 端共享相同信息顺序：

1. 圆形头像。
2. 姓名、中文位置和余码身份牌。
3. 底牌或牌背。
4. 朝向底池的本街下注筹码及金额。
5. 弃牌、思考、行动中或 ALL IN 状态。

头像、身份牌、底牌和下注筹码必须是独立元素。任何视口中不得用头像承载余码，不得用下注标签覆盖头像，也不得让牌背与身份牌重叠。

## 操作区同步

- 保留已实现的三段式结构：上方五节点横杆；下方左侧下注尺度、中间手牌、右侧三个固定动作位。
- PC 与手机操作按钮改用同一套 Image 2 筹码底图。
- 非法按钮固定原位变暗；主动作到最大金额时使用 ALL IN 黑金资产与金字效果。
- 左侧半池、2/3池、底池使用克制的黑皮革按钮，不与右侧实体操作筹码争夺视觉焦点。

## 响应式布局

- iPhone 14 Pro Max 竖屏是移动端主基准；同时验证 430×760 与 932×430。
- PC 验证 1440×900 与最小窗口 1100×760；牌桌区不得侵入右侧分析栏。
- 移动端头像目标 52–60 px；PC 头像目标 58–68 px。
- 手牌和公共牌保持现有可读下限，红桃/方片为红色，黑桃/梅花为黑色。
- 牌面点数与花色不得随卡片整体等比缩小；紧凑视口优先减少内边距，保证点数和花色仍清楚。

## 状态与动画

- 下注动画使用新筹码图片沿现有路径飞向底池，保持当前防连点和播放节奏。
- 思考状态只强化当前头像外圈并保留三点动画。
- 弃牌降低人物饱和度并显示明确印章，不隐藏已经投入的筹码。
- ALL IN 使用现有逻辑触发，不因视觉替换改变规则事实。

## 工程边界

- 不修改牌局规则、GTO/对手策略、行动顺序、合法下注、筹码结算和持久化。
- 不增加远程运行依赖；素材必须随桌面包和 PWA 一起离线交付。
- 不把文字烘焙进头像或通用筹码图片。
- 公共发布包继续使用匿名玩家名称；本地名称配置不进入 Git。

## 验收

- 六张头像和全部筹码素材均为新生成资源，移动与 PC 使用同一文件。
- 六个头像人物与样图一致；公共牌、桌面底牌和操作区手牌在同一张截图中具有一致的牌纸、字体与花色语言。
- 组件测试验证稳定头像映射、下注金额、状态层和固定操作位。
- 视觉测试验证五种视口无头像/余码/牌/筹码重叠，公共牌和底池无遮挡。
- 对照两张确认设计稿完成 `design-qa.md`，P0–P2 问题清零。
- 完整通过单元测试、代码检查、构建、PWA 离线与桌面/移动截图测试。
