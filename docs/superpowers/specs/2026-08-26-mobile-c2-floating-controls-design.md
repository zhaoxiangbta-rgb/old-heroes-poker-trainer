# 手机牌桌 C2 悬浮操作设计

## 目标

在 iPhone 14 Pro Max 竖屏中取消会遮挡牌桌的大面积下注面板。轮到英雄行动时，操作控件以独立悬浮元素出现，底池、公共牌、对手余码、本街投入与英雄底牌始终可见。

## 视觉方向

- 延续“老英雄牌局”的深色现代扑克风格：深青绿色牌呢、炭黑结构、香槟金重点色、暗酒红危险动作。
- 采用 C2 的现代赛事转播式信息层级，减少皮革、厚边框和大面积金色装饰。
- 按钮为轻量实体胶囊：浅层压下结构、细窄筹码刻线、小范围内高光。不得退化成普通网页矩形按钮。
- 不使用整块操作面板、抽屉、毛玻璃矩形或不透明遮罩；允许各控件自身带极小范围的半透明暗底和阴影。

## 玩家头像

- 每位玩家保留圆形头像，但不限定人像。
- 默认头像使用轮廓差异明显的个人徽章，例如狼、锦鲤、猎鹰、麻将牌、罗盘、棋子。
- 每个头像采用不同轮廓和克制的独立强调色，保证在小尺寸时仍能立即区分。
- 头像不得影响玩家名称、中文位置、余码和本街投入的可读性。

## 英雄回合布局

从左到右固定为三列：

1. 左侧：英雄两张底牌、中文位置与余码。底牌尺寸不小于当前公共牌，并保持红色红桃/方片、黑色黑桃/梅花。
2. 中间：采用 B 版机械推杆造型，而非 C2 概念图中的单根细线。推杆由窄幅哑黑金属槽体、细金色分段刻度、圆形黄铜推钮和底部金额徽章组成，顶部嵌入 `ALL IN` 标签。推杆可以向上侵入牌桌中部，但整体宽度保持紧凑，不得覆盖公共牌、底池或玩家信息。
3. 右侧：两个紧凑椭圆动作按钮。上方为暗酒红“弃牌”，下方为香槟金动态主按钮。

底部导航上方横向并排三个次级预选按钮：`半池`、`2/3池`、`底池`。不显示“最小”预选按钮。

## 下注交互

- 面对下注时，推杆最低点等于合法跟注金额；主按钮显示 `跟注 N`。
- 无人下注时，推杆最低点等于最小合法下注；仍保留独立的“过牌”合法动作，主按钮按当前选择显示 `下注 N`。
- 推杆上移超过最低点后，主按钮自动变为 `加注到 N` 或 `下注到 N`。
- 推杆顶部为 `ALL IN`，达到最大合法投入时主按钮显示 `ALL IN N`。
- 松开推杆只选择金额，不自动提交。点击动态主按钮才提交动作。
- 点击半池、2/3 池或底池只更新推杆与金额，不自动提交。
- 提交后立即锁定全部动作控件，避免重复点击跨越多个行动阶段。

## 可见性与尺寸

- 底池数字、公共牌、所有对手余码与本街投入不得被操作控件遮挡。
- 英雄底牌不得被底部导航、预选按钮或安全区裁切。
- 竖屏操作区不得形成完整背景块；横屏继续采用左牌桌、右操作区布局，但沿用同一按钮和头像视觉语言。
- 所有点击目标不小于 44 × 44 CSS 像素；预选按钮可以视觉更小，但实际点击区必须满足该尺寸。
- 尊重安全区、减少动态效果设置，并保持键盘/辅助功能名称准确。

## 状态与动画

- 非英雄回合完全隐藏推杆与动作按钮，只显示牌桌行动和思考动画。
- 推杆移动时金额即时更新；动态主按钮文字以短促淡入切换，不使用弹跳动画。
- 黄铜推钮随手指连续移动，槽内已经过区间以克制的暖金色填充；分段刻度仅帮助判断位置，实际金额仍按每个合法整数连续选择。
- 按钮按下采用 1–2px 下沉和亮度变化，动作提交后立刻进入锁定状态。
- 对手头像思考状态只增加细金色呼吸环，不改变座位尺寸。
- 玩家下注、跟注或加注时，2–4 枚筹码从行动者座位沿短弧线飞向该玩家的本街投入区；筹码到位后再更新投入数字，保证行动顺序清楚。
- 筹码动画持续约 260–360ms，按下注距离和金额轻微变化；多人行动必须依次播放，不得让所有投入数字瞬间同时变化。
- 筹码落点播放一组短促、低延迟的本地合成筹码碰撞声。下注金额越大，可适度增加第二层低频碰撞，但不得拉长对手行动等待。
- 音效完全离线生成，遵守设置中的音效开关及系统静音状态；关闭音效后不得影响动画时序。
- 全下动作触发一次金色 `ALL IN` 艺术字：斜体衬线字、香槟金到亮金渐变、细微金属高光与短促光扫。文字在牌桌中央上层出现，但避开公共牌和底池数字。
- `ALL IN` 特效持续约 700–900ms，随后缩为行动者座位旁的金色全下徽章；不得持续覆盖后续发牌或摊牌。
- 全下使用更有重量但不刺耳的筹码落桌声；同一动作只播放一次，重放时必须遵循固定事件序列。

## 验收

- iPhone 14 Pro Max 竖屏截图中，英雄底牌、底池、五张公共牌、五位对手余码与本街投入同时可见。
- 面对下注时最低点显示跟注；上推后同一按钮显示加注；全下需要再次点击主按钮提交。
- 预选按钮仅有半池、2/3 池、底池，且三者横向排列。
- 非英雄回合不存在任何下注控件。
- 横竖屏无横向溢出、无控件与牌面重叠。
- 单次下注会依次出现筹码飞行动画、投入数字更新和本地筹码声；快速连续点击不会重复播放或重复提交。
- 全下会出现一次金色 `ALL IN` 艺术字并收束为座位徽章；特效不遮挡公共牌、底池或结算结果。
- 关闭音效时所有牌局与动画仍可正常完成，且不会调用网络音频资源。
- 前端行为测试、WebKit PWA 离线测试、移动视觉几何测试和 Rust 局域网传输测试全部通过。
