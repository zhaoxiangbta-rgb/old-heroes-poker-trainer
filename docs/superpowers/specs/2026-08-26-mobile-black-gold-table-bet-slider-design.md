# 手机黑金牌桌与纵向下注推杆设计

## 目标

重做独立离线 PWA 的手机训练牌桌，使其在 iPhone 14 Pro Max 竖屏上更接近成熟扑克产品：信息更大、更直观、装饰更少。轮到英雄行动时才显示下注托盘，使用纵向推杆选择合法区间内的任意整数金额，并通过独立按钮确认提交。

本改动只重塑移动端牌桌和行动控件。桌面端布局、扑克规则、策略、训练评分、存储格式和历史重放语义保持不变。

## 已确认的视觉方向

采用 A2“黑金俱乐部”：

- 深黑绿色牌桌，低饱和金色边线和行动强调色。
- 仅主操作使用金色，弃牌使用克制的暗红色，其余控件保持中性。
- 公共牌、英雄手牌、底池、玩家名称和筹码数字优先放大。
- 玩家使用清晰的姓名、位置、筹码和简洁身份圆标，不使用占空间的大头像。
- 减少嵌套卡片、发光装饰和细碎标签，避免现有手机界面“太花、太小”。
- 非英雄行动阶段保持完整牌桌；英雄行动阶段从底部升起半屏下注托盘，仍保留公共牌、底池和主要对手信息。

视觉伴侣中确认的参考稿位于 `.superpowers/brainstorm/8950-1787723900/content/a2-two-states-v3.html`，仅作为设计参考，不进入生产包。

## 信息层级与布局

### 非英雄行动状态

- 顶部仅保留牌局名称、当前街和在局人数。
- 底池置于牌桌视觉中心上方，金额为最高层级数字。
- 公共牌居中，保持红桃/方片红色、黑桃/梅花深色。
- 六人座位沿椭圆牌桌排布，名称、中文位置、剩余筹码和本街投入必须可读。
- 手机视图按英雄座位旋转显示，使英雄始终靠近底部；只改变视觉映射，不改变引擎座位、行动顺序或重放数据。英雄手牌明显大于玩家标签且不与底部导航重叠。
- 当前说话玩家用单一金色描边或呼吸状态提示，不堆叠多种特效。
- 对手行动仍逐个播放，思考状态和筹码移动保留现有时序。

### 英雄行动状态

- 下注托盘从底部升起，占竖屏约 44% 至 48%。
- 公共牌与底池在托盘上方保持可见；被遮挡的下方座位可以降低对比度，但不能改变牌局状态。
- 托盘顶部显示“下注到”或“加注到”和当前选定总额。
- 中央为纵向推杆；左右两侧为四个快捷尺寸。
- 底部为当前合法的直接动作和确认动作。

## 行动状态

移动端使用独立的 `MobileActionSheet`，但消费现有 `GameState.legal` 并调用现有行动提交函数。不得复制或重新计算规则。

### 可以过牌

- 显示“过牌”和“下注”。
- 推杆区间为最小合法下注额至英雄最大合法投入。
- 点击“过牌”立即提交；点击“下注”提交推杆当前金额。
- 不显示“弃牌”和“跟注”。

### 面对下注且允许加注

- 显示“弃牌”、“跟注 N”和“加注”。
- 推杆区间为最小合法加注到金额至最大合法加注到金额。
- “跟注 N”中的 N 表示本次需要支付的筹码，托盘顶部金额表示本街总投入到。

### 面对下注但加注权未重新开放

- 只显示“弃牌”和“跟注 N”。
- 不显示推杆、快捷尺寸或加注按钮。
- 清楚提示“短全下未重新开放加注”，但不占用主要操作区域。

### 不需要英雄行动

发牌、对手思考、对手行动播放、结算、复盘和牌局结束时，下注托盘完全隐藏。

## 纵向推杆

- 最低点严格等于 `minRaiseTo`；最高点严格等于 `maxRaiseTo`，即 ALL IN。
- 合法范围内按 1 筹码步进，可以选择任何整数金额。
- 拖动过程使用指针捕获，手指移出轨道后仍持续更新，松手结束选择。
- 松手只确定金额，不提交行动。
- 到达最高点时，顶部标记和金额反馈切换为金色 `ALL IN`；最终仍需点击“下注”或“加注”确认。
- 金额变化必须立即反映在托盘顶部，并同步更新推杆位置。
- 无障碍语义使用范围控件，提供当前值、最小值、最大值和“本街投入到”的说明。

## 快捷尺寸

两侧固定显示：

- 左侧：`½池`、`⅔池`
- 右侧：`底池`、`最小`

快捷尺寸使用现有底池和合法动作事实计算目标值，再限制到 `[minRaiseTo, maxRaiseTo]`，最后取合法整数。点击只更新金额和推杆位置，不自动提交。多个快捷尺寸落到同一合法金额时仍可显示，但需要通过金额反馈明确结果。

## 防误触与状态同步

- 英雄提交任何动作后，所有行动控件立即锁定。
- 同一英雄决策只允许发送一次；重复点击不得推进多个行动或多条街。
- 托盘随后按现有行动播放时序收回，由对手逐个行动。
- 若控件打开期间合法范围变化，当前金额重新限制到新范围；已不再合法的操作立即隐藏或禁用。
- 如果提交被规则引擎拒绝，托盘保持打开，显示明确错误并恢复可操作状态，不静默失败。

## 动效

- 托盘约 180ms 自底部升起或收回，使用快速、克制的减速曲线。
- 推杆移动时金额数字提供轻微缩放反馈；快捷尺寸使推杆平滑移动。
- 到达 ALL IN 只使用一次金色强调，不添加循环闪烁。
- `prefers-reduced-motion: reduce` 下取消位移动画和金额缩放，保留状态颜色和文字反馈。

## 组件边界

- `MobilePokerTable`：手机专用牌桌排布和信息层级。
- `MobileActionSheet`：根据合法动作决定是否展示托盘及底部按钮。
- `VerticalBetSlider`：把合法整数金额与纵向手势位置双向映射。
- `mobileBetSizing`：纯函数，计算快捷尺寸并限制合法范围。
- 现有 `PokerTable`、`ActionControls` 和桌面 CSS 保持桌面职责；共享牌面、行动回执和规则数据，不共享易造成桌面回归的手机布局样式。

## 响应式与安全区

- 主验收视口为 iPhone 14 Pro Max 竖屏。
- 使用 `env(safe-area-inset-*)` 避开灵动岛、Home 指示条和浏览器安全区。
- 横屏保持所有合法动作可操作，允许缩短托盘高度，但不得让按钮或英雄手牌重叠。
- 最小触控目标为 44×44 CSS 像素。

## 存储与离线

本功能不改变 IndexedDB 模式、JSON 导入导出格式、随机种子或牌局快照。PWA 更新后沿用现有 Service Worker 版本缓存机制；首次加载新版资源后仍须能够断网重启并继续训练。

## 验证

### 单元与组件测试

- 推杆最低值、最高值、任意中间整数值和 ALL IN 映射。
- 四种快捷尺寸的计算、取整和合法范围限制。
- 可以过牌、面对下注、禁止再加注和英雄非行动状态的控件显隐。
- 松手不提交；点击确认才提交。
- 提交锁定与重复点击防护。
- 合法范围变化后的金额重新限制和错误恢复。

### 牌局与视觉验收

- 在 iPhone 14 Pro Max 竖屏完成至少一整手牌。
- 确认非英雄行动时无下注托盘；英雄行动时托盘出现；提交后托盘收回。
- 确认公共牌、底池、手牌、玩家筹码和本街投入均可读且无重叠。
- 确认对手继续逐个思考、行动和移动筹码。
- 覆盖过牌/下注、弃牌/跟注/加注、ALL IN 和短全下未重新开放加注。
- 运行完整前端、规则引擎、PWA 离线重载和移动视觉回归测试。

## 非目标

- 不修改 GTO 或朋友局策略。
- 不改变行动顺序、筹码、底池、边池或摊牌规则。
- 不给玩家新增真人头像、联网账户或多人联网牌局。
- 不在本轮重做历史、设置、弱点报告和复盘页面。
