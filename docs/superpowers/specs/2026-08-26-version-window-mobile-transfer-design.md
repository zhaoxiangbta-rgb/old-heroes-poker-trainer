# 版本识别、默认窗口与手机传输设计

## 目标

- 用户启动程序后无需进入设置即可确认当前版本。
- macOS 首次启动的窗口完整容纳桌面牌桌和操作区。
- iPhone 在局域网中稳定接收手机版单页，不再出现“意外终止了连接”。

## 界面

- 桌面顶部在线状态旁常驻显示 `v1.1.5`，保持次要视觉层级。
- 设置页底部显示产品名、版本号和“桌面本地版”，用于截图排错。
- 移动版顶部同样显示版本号，便于确认手机实际加载的版本。

## 窗口

- 默认窗口设为 1440×900。
- 最小窗口设为 1100×760，仍保留自由缩放。
- 不保存或恢复可能小于新最小尺寸的旧窗口尺寸。

## 手机传输

- 保留单页内嵌主程序，避免第二次脚本请求失败。
- 当浏览器声明支持 gzip 时，局域网服务压缩超过 4KB 的静态资源。
- 返回正确的 `Content-Encoding`、`Content-Length` 和 `Vary`，不支持 gzip 的客户端仍接收原始内容。

## 验证

- 组件测试验证桌面和移动顶部版本号、设置页版本信息。
- 配置测试验证默认窗口和最小窗口尺寸。
- Rust 测试验证大首页启用 gzip 且压缩体小于 150KB。
- WebKit 直接访问真实局域网服务，验证加载和主脚本免二次请求。
- 完成全量前端测试、Rust 测试、构建和 macOS DMG 打包。
