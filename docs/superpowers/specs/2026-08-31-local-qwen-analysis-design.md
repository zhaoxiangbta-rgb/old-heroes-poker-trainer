# 本地 Qwen 解析增强设计

## 目标

在不替换现有本地规则、Solver、对手决策和结算的前提下，接入 OpenAI-compatible 本地模型，提升盘中解析和盘后复盘的清晰度、针对性与可读性。

首个验证服务：

- 接口：`http://192.168.120.86:8081/v1/chat/completions`
- 模型：`Qwen3.5-9B-Q8`
- 密钥：可选

## 不在本阶段的范围

- AI 不参与发牌、洗牌、底池、边池、合法动作或输赢结算。
- AI 不决定对手的弃牌、跟注、加注和下注尺寸。
- AI 不修改本地 Solver 给出的推荐动作、EV、权益、范围概率和玩家画像事实。
- 未配置模型、无网络或请求失败时，不降低现有本地功能。

## 双轨运行

### 纯本地模式

未启用 AI、连接失败、超时、返回格式错误或事实校验失败时，继续显示现有本地分析和复盘。牌局不得因 AI 请求而卡住。

### AI 增强模式

本地事实先显示，AI 后台异步生成教练解释。AI 结果只能覆盖“解释区”，不能覆盖规则数值和推荐动作。

## 组件边界

### 1. 模型客户端

- 同时支持服务根地址和完整 `chat/completions` 地址，避免重复追加路径。
- API Key 可选；有密钥时仅从 macOS Keychain 读取，无密钥时不发送 `Authorization` 头。
- 支持连接测试、盘中解析和整手复盘三种请求。
- 盘中超时预算 4 秒；盘后复盘超时预算 30 秒。
- 对同一牌局状态哈希去重，并取消已过时的盘中请求。

### 2. 本地事实包

发给模型的不是整个内部状态，而是版本化、最小化的结构化事实：

- 街、位置、人数、底池、SPR、面对下注和底池比例。
- 英雄底牌、公共牌、当前最大牌型，以及“手牌是否对成牌有私有贡献”。
- 权益、所需胜率、干净/脏补牌和升级路径。
- 各对手范围分组及概率、行动线、玩家画像和置信度。
- Solver 推荐动作、尺寸、候选 EV 与当前动作意图。
- 明确的禁止陈述，例如“公共牌对子不得表述为英雄手牌击中一对”。

所有比例由本地先计算成明确字段，不让模型自行把“下注到 2、底池 6”换算成比例。

### 3. 盘中解析

显示顺序固定为：

1. 本地当前牌型与手牌贡献。
2. 升级可能与风险牌。
3. 对手范围的前三类及概率。
4. 本地推荐动作与尺寸。
5. AI 的两至四句中文理由。

AI 加载时不显示阻塞弹窗，只在解释位置显示轻量状态。玩家一旦完成当前动作，迟到的解释不再覆盖新状态。

### 4. 盘后复盘

- 一手只发起一次 AI 复盘请求。
- 输入是本地深度复盘的结构化摘要，而不是让模型重新算牌。
- 输出固定为：整手结论、翻前、翻牌、转牌、河牌、关键转折、下次可执行的一条练习规则。
- 没有行动的街不生成空段落，同一事实不在多个章节重复。
- 保留本地数值明细，AI 只生成上层教练解释。

## 输出校验

AI 返回必须通过 JSON Schema 和事实守门：

- 推荐动作和尺寸必须与本地事实相同。
- 百分比、筹码和位置不得出现本地事实之外的新数值。
- 牌型与手牌贡献必须与本地评估一致。
- 不得声称知道未摊牌对手的确切底牌。
- 失败时丢弃整个 AI 结果，保留本地解释，不将半正确内容混入 UI。

## 数据与隐私

- Base URL、模型名和启用状态保存在本地设置。
- API Key 只保存在 Keychain，不进入 SQLite、日志或 JSON 导出。
- 不在日志中记录完整请求体、响应体或密钥。
- 历史牌局可保存已通过校验的 AI 解释、模型名、事实包版本和生成状态，但不保存密钥。

## 错误处理

- 不可达：标记本次 AI 不可用，回退本地。
- 超时：取消本次等待，不自动阻塞重试。
- HTTP 错误：显示简短状态，不暴露响应原文或密钥。
- JSON 错误或事实冲突：丢弃 AI 结果，保留本地内容。
- 连续失败：当前手不再请求；下一手可恢复尝试。

## 测试与验收

### 客户端

- 根地址和完整路径都生成唯一正确 URL。
- 有/无 API Key 都可请求对应服务。
- 超时、HTTP 错误、无效 JSON 和事实冲突均回退本地。
- 密钥不出现在数据库、日志、导出和测试快照中。

### 牌局事实

- `J2 + A44` 被描述为未用手牌配对的空气，不是“普通一对”。
- `99 + 932` 被描述为三条。
- 庄位不得被写成翻前不利位置。
- “底池 6，下注到 2”必须使用本地给出的比例，不允许模型写成“2 倍底池”。
- 未摊牌者只说范围类型和概率，不说确切底牌。

### 用户体验

- AI 未返回时已能正常决策。
- 盘中 AI 迟到不覆盖新的决策状态。
- 盘后复盘无重复章节，且与盘中使用同一本地事实。
- 关闭 AI 后，行为与未接入前一致。

## 实测基线

2026-08-31 对 `Qwen3.5-9B-Q8` 实测：

- 简单牌型 JSON：HTTP 200，约 1.03 秒，正确识别三条。
- 公共牌成对测试：约 2.22 秒，正确识别英雄为空气；但错将“下注到 2、底池 6”解释为“2 倍底池”，因此必须由本地预先计算比例并校验输出。
- 整手逐街复盘：HTTP 200，约 6.73 秒，能保留本地推荐、范围与胜率结论。
